# data/ — справочные классификаторы

`packaging_codes.json` — классификатор видов груза, упаковки и упаковочных
материалов: приложение № 12 к решению Комиссии Таможенного союза от 20.09.2010
№ 378 (в редакции от 01.04.2025). 364 кода.

Именно на него ссылается формат ЭТрН в реквизите `@ВидТар` («Принимает значение
в соответствии с классификатором видов груза, упаковки и упаковочных
материалов»). Код — ровно два символа.

Снято 09.09.2026 из текста приложения в правовой базе
(https://sudact.ru/law/reshenie-komissii-tamozhennogo-soiuza-ot-20092010-n_11/prilozhenie-n-12/),
разобрано скриптом, выборочно сверено глазами.

Если ФНС или ЕЭК обновят классификатор — заменить файл целиком, а не править
руками отдельные строки: расхождение с официальным списком означает отказ
оператора.
