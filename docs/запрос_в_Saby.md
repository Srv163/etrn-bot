Здравствуйте.

Мы выписываем электронные транспортные накладные как грузоотправитель, объём —
до 10 накладных в день. Файл Титула 1 (информация грузоотправителя) формируем
у себя: формат ФНС по приказу ЕД-7-26/1065@, версия 5.01, часть 973, КНД 1110339,
схема `ON_TRNACLGROT_1_973_01_05_01_02.xsd`, кодировка windows-1251. Файл
проходит валидацию по XSD.

Прошу ответить по пунктам:

1. **Загрузка готового XML.** Можно ли загрузить в Saby уже сформированный файл
   Титула 1 из XML — не заполняя накладную в веб-интерфейсе руками? Если да:
   в каком разделе это делается и на каком тарифе доступно?

2. **Имя файла обмена.** По приказу имя имеет вид
   `ON_TRNACLGROT_A_E_O_W_ГГГГММДД_N.xml`, где `A`, `E`, `O` — идентификаторы
   участников ЭДО (три символа кода оператора плюс GUID участника).
   Подставляет ли Saby эти идентификаторы и имя файла самостоятельно при
   загрузке, или файл должен приехать уже с правильным именем? Если второе —
   где в Saby посмотреть идентификатор ЭДО нашей организации, а также
   идентификаторы перевозчика и грузополучателя?

3. **Проверка перед отправкой.** Проверяет ли Saby загруженный файл по
   контрольным правилам приказа (Schematron) до отправки, и где смотреть
   протокол ошибок, если файл не принят?

4. **Если загрузка XML недоступна** — какие каналы передачи есть для нашего
   случая: Saby Connect с каталогом «Отправляемые», интеграция через API
   (`СБИС.ЗаписатьДокумент` / `СБИС.ЗаписатьВложение`), что-то ещё? Что нужно
   подключить и на каком тарифе?

5. **Момент оформления.** Формат Титула 1 требует фактические дату и время
   прибытия и убытия транспортного средства с погрузки
   (реквизиты `ФДатВрПриб`, `ФДатВрУбыт`, оба обязательные). Как в Saby принято
   оформлять накладную, если машина ещё не уехала с погрузки: титул формируется
   только после убытия, или предусмотрен другой порядок?

6. **Заявка перевозчику и поручение экспедитору.** С 01.09.2026 они тоже
   электронные: электронная заявка — формат ФНС по приказу ЕД-7-26/108@
   (КНД титула грузоотправителя — в схеме `ON_ZAKZV…_969`), электронное
   поручение экспедитору — формат по приказу ЕД-1-26/277@ (титул клиента,
   КНД 1110486). Можно ли загрузить в Saby готовые XML этих документов так же,
   как ЭТрН? Если да — где и на каком тарифе. Если нет — как их сейчас оформляют
   ваши клиенты.

Подписывать и отправлять документы будем сами своей УКЭП в Saby — нужна только
возможность загрузить подготовленный файл.

Спасибо.
